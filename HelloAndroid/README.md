## 📖 About

HelloAndroid is my first Android application, developed as part of my journey into Android development.

The project focuses on understanding the fundamentals of creating Android applications using **Java, XML and Android Studio**.

## 🛠️ Built With

- ☕ Java
- 🎨 XML
- 📱 Android Studio
- ⚙️ Gradle

## 🎯 What I'm Learning

- Understanding Android Studio
- Exploring Android project structure
- Working with Java Activities
- Designing interfaces using XML
- Running applications on the Android Emulator

## 🚀 Future Improvements

- Create an interactive home screen
- Add buttons and user interactions
- Explore multiple Activities
- Improve the user interface
- Add more Android features as I learn
